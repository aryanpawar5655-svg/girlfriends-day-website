# Photos for the carousel

Drop 3 photos of you two here, named exactly:

- `photo1.jpg`
- `photo2.jpg`
- `photo3.jpg`

Recommended: landscape (4:3), 1200×900 or larger, JPG or PNG. If any file is missing, the site shows a pretty pink placeholder card so nothing breaks.

To change captions ("The moment I knew 💗", "Every laugh with you 🌸", "Forever this feeling ✨"), edit `<figcaption>` in `index.html`.
